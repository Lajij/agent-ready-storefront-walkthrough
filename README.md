# Vercel Shop: agent-ready storefront walkthrough (Saltbush & Ridge)

A clickable, six-stage walkthrough of Vercel Shop, Vercel's open-source Next.js storefront template for Shopify
built on Shopify's Hydrogen SDK (blog: https://vercel.com/blog/vercel-and-shopify-make-agents-first-class-shoppers,
repo: https://github.com/vercel/shop), told through a fictional Australian outdoor retailer whose AI-assistant
shoppers keep leaving without buying.

Stages: the new shopper (AI-assistant traffic rising, converting badly) → today's screen-scrape (wrong price, unknown
stock, sale lost) → one product URL serving a page to people and readable product info to agents → the agent
searching, checking stock and building a cart over MCP → the shopper confirming on the store's checkout →
simulated business outcome.

All data is simulated. Saltbush & Ridge is a fictional company. No Shopify store, secrets or external API calls.

- `TALK_TRACK.md`: 2–3 minute spoken script
- `LINKEDIN_CAPTION.md`: post caption

Built with Next.js, Tailwind and Geist. `npm run dev` to run locally.
